# 厦与珈

厦与珈是一个 macOS 桌面应用，用来编辑中文 Beamer 学术幻灯片。界面里的文字改动会写进项目文件，右侧用真实 LaTeX 编译出的 PDF 预览。同一份内容可以导出 PDF、PPTX、完整 LaTeX 工程和 AI 写作包。

## 下载

macOS Apple Silicon 安装包在 [GitHub Releases](https://github.com/13246677559-droid/xia-yu-jia/releases/latest) 提供。下载 dmg，挂载后把“厦与珈.app”拖进“应用程序”。

应用使用 ad-hoc 签名，没有经过 Apple 公证。首次打开时右键点击应用并选择“打开”，或者执行下面的命令。

```bash
xattr -dr com.apple.quarantine "/Applications/厦与珈.app"
```

## 项目与导出

- 项目默认放在 `~/Documents/厦与珈/`。每个项目是一个文件夹，里面有 `project.json` 与 `assets/`。
- 导出文件放在 `~/Downloads/厦与珈导出/`。
- 配色有七套：武大珞珈绿、武大东湖蓝、武大黉瓦绿、武大春藤紫、武大秋桂金、武大晨雾灰、厦大嘉庚蓝。编辑器顶部的配色胶囊打开配色画廊，可以并排预览当前页。武大六套不使用红色，厦大配色的点缀色为嘉庚红。
- 每页标题栏右侧是武汉大学白色镂空校徽。
- 每页正文可以整页、上下两版、左右两版或四分版。分版内可以放多个内容块，块可以拖动换版，字体字号不变。
- 表格的文字对齐按列设置，整表位置单独设置左右中。整表位置以要点文字边界为准，表注跟着表格移动并在表宽内居中。表格过宽时导出会报错，不会把字号缩小。
- 导出 PDF 时可以选择“Edge 放映”版本。这个版本在页面上下各加 0.5 厘米安全边，顶部边色跟随主题主色，避免 Edge 全屏演示裁掉顶部导航。
- 每个要点模块可以写组标题，组标题下面放多条要点。一条要点由圆圈和正文组成，正文长度不设上限。辅助说明与正文同字号，用灰色和缩进区分。
- 页面标题不必每页都不同。连续几页讲同一个问题，可以共用一个页面标题。
- 项目最后有一张固定的结尾页。中间文字可以改，汇报人和汇报时间取自封面字段。
- 当前版面只有一个内容块时，块标题栏会出现居中按钮，可以让它在版面里垂直居中。默认保持原来的顶部对齐，字体字号不变。
- 所有内容块都可以在右侧预览里直接拖动，编辑器里也有横向和纵向位置滑杆。块可以重叠，越出版面时导出前会拦下。页面标题、页脚和脚注仍固定。
- 代码块用等宽字体，注释行以 #、//、%、-- 开头时显示为灰色。文献块按 APA 写，悬挂缩进。脚注固定在页面底部自动编号，字体小，默认浅灰色。

## 编译环境

应用自带 Tectonic 与本地 LaTeX 宏包，不需要安装 MacTeX，也不需要联网编译。

中文字体使用 FandolHei，随 Tectonic 宏包提供。PDF 里的中文可以正常复制与检索。

## 开发

```bash
cd app
npm install
npx tauri dev
```

打包。

```bash
cd app
npx tauri build --bundles app
```

主题源文件在 `latex/`。应用、LaTeX 工程导出和 AI 包导出都从这一处读取主题。

## AI 包

编辑器右上角“导出 AI 包”会生成一个 zip。里面包含当前全部内容、主题模板、系统提示词、写作规范和校验清单。把解压后的文件夹交给任意 AI 会话即可。

AI 修改完 `03-内容.yaml` 后，用同一个菜单里的“导入内容 YAML”回到应用，应用会重新生成 LaTeX。

AI 包的 `05-示例/` 可以独立编译。

```bash
tectonic 完整示例.tex
```

AI 包里同时有 `07-结构化Markdown规范.md`。把这份规范和知识文本交给 AI，AI 输出一份结构化 Markdown。回到应用首页，点击“从 Markdown 新建”，选择这份文件，应用会在本地校验、读取同目录下的图片、新建项目并打开编辑器。整个过程不联网。

规范正文在 `docs/结构化幻灯片Markdown规范.md`。

## 目录

- `app/` React 前端与 Tauri 后端
- `latex/` Beamer 主题源文件
- `assets/` 校徽与官方色卡
- `docs/` 设计截图与结构化 Markdown 规范
- `tools/tectonic/` Tectonic 二进制
